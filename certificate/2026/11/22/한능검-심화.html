삼국 시대

고구려

- 진대법, 태학과 경당(인재 양성, 소수림왕)

- 불교: 쌍영총벽화, 승려 순도, 소수림왕(고국원왕의 아들)

- 장군총(돌무지 무덤)

백제

- 마지막 수도 부여, 삼국시대에 부여, 좌평 얘기나오면 백제임

- 6좌평(달솔 등의 관등)

- 근초고왕: 고국원왕 kill (그래서 보복으로 장수왕한테 개로왕 전사), 한강차지, 서기 편찬(한강 차지~)

- 무령왕: 22담로, 백가의 난 진압, 중국 남조

- 성왕: 사비 천도, 국호 남부여, 진흥왕 뒤통수로 나제동맹 결렬(관산성(충북) 전투에서 전사), 달기를 보내 고구려의 도살성을 함락

- 무왕: 미륵사

- 송산리 고분(무령왕릉), 능산리 고분(사비, 부여)

- 고구려에 태학과 경당이 있고 신라에 국학이 있다면 백제엔 오경박사(유교)가 있따

신라

- 지증왕(22대): 국호 신라, 동시전 설치, 우경 장려, 우산국 복속

- 법흥왕: 병부와 상대등 설치(관청, 중앙집권체제), 율법과 불교(이차돈 순교), 건원 연호

- 진흥왕: 화랑도(게이화장) 개편, 거칠부로 하여금 국사편찬, 나제 동맹 배신 깜, 4개의 순수비

- 문무왕: 백제 부흥 진압(복신, 도침), 고구려 부흥 지원(안승을 보덕국 왕으로), 외사정을 파견(지방관 감시), 상수리제도(기인제도로 발전)

- 신문왕(통일신라): 녹읍 폐지(대신 관료전 지급, 진골 귀족 조질려고), 김흠돌의 난 진압(통일직후), 국학(박사와 조교를 두어 유학 교육), 9주5소경, 9서당

- 강수(문장가): 무열왕~문무왕, 6두품(관등제한 벽느낌. max불가능), 청방인문표(외교 문서)

- 설총: 이두(우리말 표기법), 아빠가 원효대사 해골물, 신문왕한테 화왕계 들려주~

- 원광(승려): 걸사표, 세속5계

- 원효대사(마음먹기에 달림): 불교 대중화, 화쟁사상, 일심사상, 금강산매경론 저술

- 의상(승려): 당으로 건너가 불법, 화엄종, 관음신앙, 화엄일승법계도

- 혜초(승려): 왕오천축국전(인도여행, 구법순례기)

- 자장(승려): 황룡사9층목탑

- 골품제

- 화랑도(얼굴에 분칠, 청소년 민간 단체)

신라의 삼국 통일 과정

- 살수대첩(을지문덕) -> 천리장성 축조 -> (배경) 백제 의자왕 신라의 대양성 공격 -> 막리지의 난(연개소문 정변, 영류왕 시해) -> 안시성전투(연개소문, 보장왕) -> 김춘추(무열왕) 개빡침 -> 나당동맹(당나라는 고구려한테 빡침) -> 백제 공격 ㄱㄱ 황산벌 전투에서 승리 -> 흑치상지의 백제 부흥 운동 시발점(임존성에서 군사를 일으킴), 복신과 도침 지도자(부여풍 왕으로) -> 나당연합의 백강 전투 승리 (백제 부흥 운동의 끝자락) -> 고구려 공격 (연개소문 없으니까 썰어버림) -> 당나라의 안동도호부 -> 고구려 부흥 운동 지원 (신라가 지원해줌, 안승을 보덕국 왕으로) -> 당나라가 뒤통수 깜, 매기전투(매소성, 기벌포)에서 신라 승리 -> 통일~

통일 신라

- 수도에 서시와 남시 설치

후삼국

- 궁예(후고구려, 신라 왕족 출신): 광평성(정치기구), 국호를 마진과 태봉으로, 철원으로 천도

- 견훤(후백제, 신라말기 군인 출신): 완산주에 나라 세움, 후당 오월에 사신 파견(겸교태보의 직을 받음), 태조 왕건에게 항복gg

남북국 시대

신라 하대

- 혜공왕 피살 이후 혼란스러움(난이 많이 발생), 난(김헌창 -> 장보고(청해진 대사 궁복, 장보고 키워드: 산둥반도에 법화원) -> 원종애노(농민) -> 적고적) -> 최치원(6두품출신, 격황소서=토황소격문) 시무 10조(진성여왕한테 빠꾸먹고 벽느낌)

- 백성에게 정전 지급(성덕왕), 독서삼품과(원성왕, 능력중시), 상수리제도(고려 기인제도로 계승됨), 임신서기석(유교공부증거~)

- 신라 경제: 동시전(동시, 서시, 남시), 청해진(해상무역), 서시와 남시(시장), 촌락 문서(민정 문서), 무역항(울산항, 당항성, 영암)

발해

- 무왕(대무예): 연호 인안, 장문휴로 하여금 등주 선빵-> 당현종이 대문예를 파견하여 발해를 치는 과정 (얼어 죽음)

- 문왕(대흠무): 3성6부(정당성, 선소성, 중대성, -> 중앙기구, 6부는 정책), 중정대(감찰업무), 연호 대흥, 수도를 상경, 동경으로

- 선왕(대인수): 말갈 복속, 최대 영토, 해동성국, 5경15부62주, 연호 건흥

- 왕자 대봉예, 대씨 가문은 발해임을 기억해(대물)

- 문적원(중앙관청), 주자감(교유기관, 고려 국자감으로 계승됨), 거란도와 영주도 등을 통해 교역

후삼국 통일

- 왕건이 궁예 몰아냄 -> 견훤이 신라 경애왕 cut -> {공고신일!} 아니 신라가 공격받네? 도와주러 감, 구하러 와줬구나! 아니 나도 잡혔어... 공산 전투에서 견훤한테 발림 -> ㄱㄷ, 다시 온다, 고창(안동)전투에서 후백제 따잇! -> 견훤이 고려에 항복 -> 신라 경순왕도 항복 -> last 일리천 전투(태조, 견훤 vs 후백제) -> 후삼국 통일

고려

- 2성6부: 도병마사(군대), 식목도감, 중서문하성(최고 중앙), 어사대(서경권), 중추원(비서), 삼사(회계, 출납)

- 관영상점(서적점, 다점 등), 은병(활구), 벽란도, 직지심체요절, 송나라 등과 무역, 팔관회와 연등회

- 5도 양계, 주현과 속현, 향.부곡.소

- 최충의 9재 학당, 문헌공도, 사학 12도 / 국자감에 7재, 양현고

- 전시과: 전지(땅, 곡물)와 시지(땔감, 산), 관등에 따라 토지 분배, 경종 -> 목종 -> 문종

- 과전법(추후 조선 세조가 직전법으로 바꿈): 이성계(조선 건국 전), 경기도 한정, 수조권만 부여(땅을 아예 준 게 아님), 수신전과 휼양전, 18등급제

- 승려 일원: 삼국유사(단군신화 고조건 얘기)

- 승려 요세: 강진 만덕사에서 백련결사, 법화신앙

- 승려 혜심: 유불일치설(유교와 불교는 하나다, 1=2)

- 승려 의천(문벌): 교관검수, 교장 간행, 해동 천태종, 교종 중심의 교선(교종, 선종)일치, 문종의 넷째아들, 불법연구 송나라 밀항, 주전도감(숙종, 해동통보)

호족지배기

- 태조 왕건: 훈요 10조, 정계와 계백료서, 흑창, 역분전(전시과 이전)

- 혜종: 왕규의 난

- 성종: 상평창(시세조절), 국자감, 12목에 지방관파견, 건원중보, 또 12목에 경학박사와 의학박사 보냄(유학교육), 의창

- 태조 왕건의 만부교 -> 정종의 광군 창설 -> 거란 1차(성종 때) -> 서희 외교 담판, 강동6주 쌀먹 -> 강조의 정변(목종 폐위, 현종 즉위) -> 거란 2차(개경 함락, 양규의 저항, 왕의 나주 피란) -> 거란 3차 -> 강감찬의 귀주대첩 -> 개경에 나성 축조(방어용도)

- 초조대장경(나중에 몽골 침입 때 불탐, 황룡사9층목탑도)

문벌귀족기

- 문종: 경시서(물가조절), 최충의 9재학당과 사학12도

- 예종: 양현고, 국자감(숙종)에 7재, 청연각과 보문각, 윤관의 별무반 (여진족 조지기), 동북9성 먹고 다시 뱉긴함

- 이자겸(금나라 사대)의 난 -> 묘청(승려임, 칭제 건원과 금국 정벌)의 서경천도운동 -> 김부식이 따잇하고 삼국사기 편찬(기전체, 우리나라 최고 역사서, 신라를 상대, 중대, 하대로 구분, 유교)

무신정권기

- 무신정변: 의종은 거제도로 보내버림

- 이의방: 중방, 김보당의 난, 조위총의 난 -> 문신이 일으킴

- 정중부: 중방, 명학소 망이 망소이의 난(농민): 향.부곡.소 중 소에서 발생

- 경대승: 중방, 도방(쫄림), 전주 관노비의 난(농민)

- 이의민: 중방, 김사미 효심의 난 (신라 부흥 운동)

- 최충헌: 교정도감(국정총괄), 만적의 난(최충헌의 노비, 농민봉기), 봉사10조

- 최우: 정방, 서방, 삼별초(몽골대항마), 강화천도(몽골 무셔웡), 대몽항쟁, 팔만대장경, 향약구급방

- 저고여 피살사건 -> 2차 침입: 최우 강화천도, 김윤후와 처인성 부곡민들이 살리타 사살, 초조대장경 소실 -> 3차 침입: 팔만대장경 제작, 황룡사9층목탑(신라) 소실 -> 5차 침입: 김윤후의 충주성 방어 -> 6차 침입: 발리고 gg, 개경 환도, 삼별초(최우)는 개경 환도 안 한다고 뻐기다가 펜타킬 (강화도 -> 진도 -> 제주도)

원 간섭기

- 공민왕이 국자감을 성균관으로 바꾸고 유학교육 강화, 농사집요, 도평마사 -> 도평의사사(권문세족)

- 삼국유사: 승려 일연, 불교사, 단군의 고조선 건국 이야기(고려 이승휴(원간섭기)의 제왕운기에도 있음)

- 이제현: 역옹패설, 만권당

신진사대부기

- 공민왕: 기철 등 친원세력(권문세족) 숙청, 쌍성총관부 탈환, 전민변정도감(토지 주인 정상화), 정방 폐지(최우가 만든 거), 홍건적 침입(이성계가 개발랐음 + 황산대첩(왜구 물리침))

- 공민왕은 기본적으로 반원 정책: 변발이랑 몽골풍 금지 때리고 정동행성 이문소 폐지

- 최무선: 화통도감, 화포, 진포대첩, 왜구 격퇴(e.g. 박위의 대마도 정벌)
